Highly customizable React Native / Expo component library powered by [Tamagui](https://tamagui.dev/).

> Status: **pre-alpha** — no components published yet. See the [monorepo README](../../README.md) and [`docs/PLAN.md`](../../docs/PLAN.md) at the repo root.

## Install

```bash
# npm
npm install ui-kraken tamagui react-native-reanimated

# pnpm
pnpm add ui-kraken tamagui react-native-reanimated

# yarn
yarn add ui-kraken tamagui react-native-reanimated
```

## Peer dependencies

`ui-kraken` expects the following peers in your Expo app:

| Package                   | Version     |
| ------------------------- | ----------- |
| `react`                   | `>=18.2.0`  |
| `react-native`            | `>=0.74.0`  |
| `react-native-reanimated` | `>=3.6.0`   |
| `tamagui`                 | `>=1.100.0` |
