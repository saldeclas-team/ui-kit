# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you version and publish your code. You can find the full documentation for it [in our repository](https://github.com/changesets/changesets).

## How to add a changeset

Whenever you make a change to `packages/ui-kraken` that should trigger a release, run:

```bash
pnpm changeset
```

Pick the packages you touched, the bump type (`patch`, `minor`, or `major` — follow [semver](https://semver.org/)), and write a summary. The CLI will drop a markdown file in this folder. Commit that file with your PR.

When the PR is merged, the `release` GitHub workflow will open (or update) a "Version Packages" PR that bumps versions and updates changelogs. Merging that PR publishes to npm.
